# StairTappers
## Overview
- Singleplayer speed-focused game where you go up the stairs as quick as you can using 'a' for left and 'd' for right.
- Menu implemeneted
- Made using python.
- Everything but sounds made entirely from scratch.
- Requires pygame to run.
### Best parts
- Object pooling for clouds and platforms to prevent inefficient memory use.
- Visual stun feedback if you take the wrong turn.
- Exponential decay camera system to make travelling feel nice.
- Very simple average stairs per second counter.
- Cool retro sounds
